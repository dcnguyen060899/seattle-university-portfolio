Business Card Design - Print Instructions

Printing Guidelines:

  • Size: Standard business card (3.5" x 2" / 88.9mm x 50.8mm)
  • Paper: 300-350 GSM cardstock recommended
  • Finish: Matte or glossy (matte recommended for professional look)
  • Print: Use browser print function (Ctrl/Cmd + P)
  • Settings: Set to actual size, no margins, landscape orientation
  • QR Code: Generate using qrcode.js library (automatically loaded)

How to Generate QR Code:

  1. Open this file in a web browser
  2. QR code will automatically generate linking to: https://duyng-portfolio.com/docs/index_portfolio.html
  3. Right-click on the cards below and select "Print" or use Ctrl/Cmd + P
  4. Ensure "Background graphics" is enabled in print settings
