# Garbage Classification Using Deep Learning

Upload an image of garbage to classify it into 6 categories:
Cardboard, Glass, Metal, Paper, Plastic, or Trash.

**Model**: ResNet34 with transfer learning (94% accuracy, 100% trash recall)

Seattle University DATA 5100 Project by Duy Nguyen
